# 🔐 FlyRank Auth API

A secure authentication system built using **FastAPI** and **Supabase Authentication**.  
The project demonstrates user registration, login, logout, JWT-based authentication, protected API routes, and interactive API testing through Swagger UI.

This project was developed as part of the **FlyRank Backend AI Engineering Internship**.

---

## 📌 Project Overview

The FlyRank Auth API is a backend authentication application designed to demonstrate how authentication and authorization can be implemented in a FastAPI application using Supabase.

The application provides both public and protected endpoints. Users can create an account, log in to receive authentication tokens, access protected resources using a valid Bearer token, and log out securely.

A simple frontend interface is also included for easier interaction with the authentication system.
